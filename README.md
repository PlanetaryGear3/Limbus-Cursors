# 使用方法

双击exe或解压缩（即zip后缀文件）后打开文件夹，右键点击install文件，选择安装。在方案下拉菜单里，选择后点击下方确定按钮即可使用。

# 常见使用问题

目前仅支持windows，安装过程中可能有报毒报错问题，可以选择关闭杀毒软件或手动替换，由于每个人的机型不同，鼠标指针可能会出现泛白重影等一系列问题，个人建议自行查找解决方案。

# Limbus-Cursors

Mouse cursors for Limbus Company, created using the ordinary wireframe-based Simple Cursor Maker.

# How to Use

Double-click the .exe file or extract the compressed (.zip) folder, then open the folder. Right-click the install file and select Install. In the scheme dropdown menu, choose your preferred option and click the OK button below to apply.

# Common Issues

Currently supports Windows only. During installation, you may encounter antivirus warnings or errors. You can choose to disable your antivirus software or manually replace the files. Due to differences in system configurations, the mouse cursor may exhibit issues such as whitening, ghosting, etc. It is recommended that you search for solutions on your own based on your specific setup.

# About Updates

A new set of mouse cursors will be released on each Sinner's birthday. Updates may be delayed due to work or health reasons. Currently available sets include: Ryōshū, Hong Lu, Heathcliff, Ishmael,Rodion,Dante,and Sinclair.
